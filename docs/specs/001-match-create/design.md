# Design 001: 試合作成と得点記録

## 依存方向

`CreateMatchView / ScoreView → MatchController → MatchRepository` とする。得点計算はFlutterに依存しない `ScoreRuleEngine` が担う。

## 主要モデル

- `MatchRecord`: 試合形式・デュース設定、現在のサービス回数、編集端末・revision・WatchセッションID、ポイントイベント履歴
- `PointEvent`: 得点側、任意の理由、サービス回数、時刻
- `MatchFormatPreset`: 5・7・9・練習3ゲームのルール値
- `ScoreSnapshot`: 再計算されたゲーム、ポイント、サービス案内、終了状態

## 画面

1. 試合作成: ペア／選手名、形式、デュース有無、先行サービスを設定する。
2. 得点入力: ポイントをゲーム数より強調し、自分・相手の大きな得点ボタン、1st／2nd、フォルト、デュース設定、取消、任意の理由チップを表示する。Watch編集中のiPhoneは閲覧専用とする。
3. 履歴: 完了試合の結果を一覧、ゲーム数・デュース設定・ポイント履歴を詳細表示し、確認後に1件ずつ削除する。
4. 集計: 全期間・過去7日・過去30日の勝率、ゲーム・ポイント取得率、得点理由、最長連続得点を表示する。

## 永続化

SQLiteの`matches`テーブルへ、検索用の日時・完了日時と`MatchRecordCodec`でJSON化した試合レコードを保存する。`settings`テーブルには自分ペアの初期入力を保存する。イベント履歴から状態を再計算するため、取消・再開・将来の書出しで同一の値を再現できる。Watchには同じJSON形式を同期し、同期Envelopeはスキーマv2とする。
