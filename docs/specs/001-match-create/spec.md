# Spec 001: 試合作成と得点記録

## 目的

個人選手がオフラインで一般ダブルスを片手操作で記録し、試合後に履歴・傾向を確認できるようにする。

## 対象と対象外

- 対象: iPhone / Android、日本語、一般ダブルス、端末内保存
- 対象外: シングルス、共有・共同編集、クラウド同期、大会固有ルール

## 受け入れ条件

- [x] 自分・相手のペア名と各2選手を入力できる
- [x] 5・7・9ゲームと練習3ゲームを選べる
- [x] 先行サービス、最初のサーバー・レシーバーを記録できる
- [x] 得点を大きなボタンで1タップ記録し、ゲーム・マッチを自動判定できる
- [x] サーブ、レシーブ、チェンジサイズを案内できる
- [x] 直前ポイントを取り消せ、未完了試合を再開できる
- [x] 得点理由を任意で7分類から記録できる
- [x] 完了試合を履歴・集計に表示し、確認して削除できる

## 保存項目

試合形式、4選手とペア名、開始／終了日時、開始サービス情報、ポイントイベント（勝者・理由・時刻）を保存する。
