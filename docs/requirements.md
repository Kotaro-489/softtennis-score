# MVP 要件

- 個人選手が、オフラインで一般ダブルスの試合を素早く記録する。
- iPhone / Androidを対象にし、データは端末内のSQLiteへ保存する。
- 機種変更はOSバックアップを基本とし、将来の書出しを妨げないイベント履歴を保存する。
- MVPに履歴・勝敗／得点傾向の集計を含める。共有、共同編集、クラウド同期は含めない。
- スコア規則は `docs/harness/rules.md` を基準とする。
- 現在の1st／2ndサービスを表示し、フォルト操作と未完了状態の復元に対応する。
- 得点理由は、そのポイントのサービス側・得点側・サービス回数に整合する候補だけを許可する。
