# 現行要件（2026-09-22）

- 個人選手が、オフラインで一般ダブルスの試合を素早く記録する。
- iPhone / Androidを対象にし、データは端末内のSQLiteへ保存する。Apple WatchはiPhoneに付属するSwiftUIコンパニオンとし、試合作成はiPhoneで行う。
- 機種変更はOSバックアップを基本とし、将来の書出しを妨げないイベント履歴を保存する。
- 履歴・勝敗／得点傾向の集計を含める。共有、共同編集、クラウド同期は含めない。
- スコア規則は `docs/harness/rules.md` を基準とする。
- 3・5・7・9ゲームのいずれも試合開始時にデュース有無を選択できる。初期値は3ゲームのみ「なし」、他は「あり」。開始後は変更できない。
- 現在の1st／2ndサービスを表示し、フォルト操作と未完了状態の復元に対応する。
- 得点理由は、そのポイントのサービス側・得点側・サービス回数に整合する候補だけを許可する。
- 得点画面はポイントをゲーム数より大きく表示し、1タップ加点・取消・フォルト操作を優先する。
- iPhoneから明示的に引き渡した試合はWatchのみで編集する。Watchは切断中も端末内に保存し、再接続後にiPhoneへ同期する。AndroidにはWatch機能を表示しない。
- Watch単体での試合作成・履歴・集計、HealthKit、コンプリケーションは対象外とする。
