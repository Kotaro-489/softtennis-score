# レビューと完了条件

PRは次をすべて満たしたときだけマージする。

- 対応するSpecと受け入れ条件が明記されている
- format、analyze、unit/widget test、integration testが成功している
- DB変更にはマイグレーションと旧バージョンからの移行テストがある
- 画面変更は対象OSで文字拡大・ダークモード・オフライン動作を確認している。Watch画面は38mm、主要操作44pt以上、VoiceOverも確認する
- 得点規則や同期形式の変更はDart／Swiftの共通ベクトル、旧データの既定値、同期バージョンを確認している
- Watch関連変更はSwiftテスト、Watchビルド、iPhoneアーカイブのCI結果を確認している
- 不要な生成物、デバッグ出力、未解決TODOが含まれていない
- 実行結果と端末確認結果をPRへ記録している。実機未確認の項目は完了扱いにせず明記している
