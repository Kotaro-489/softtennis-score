# ルールプロファイル

根拠は日本ソフトテニス連盟の2026年公開資料「ルールとマッチの進め方」とする。

- 5ゲーム: 3ゲーム先取、2-2では7ポイント先取のファイナルゲーム
- 7ゲーム: 4ゲーム先取、3-3では7ポイント先取のファイナルゲーム
- 9ゲーム: 一般形式として5ゲーム先取、4-4では7ポイント先取のファイナルゲーム
- 3ゲーム: 練習形式として2ゲーム先取

すべてのゲーム数で、試合開始時にデュースの有無を選択できる。通常ゲームは4ポイント、ファイナルゲームは7ポイントを基準とし、デュースありではそれぞれ3-3／6-6以降に2ポイント差を必要とする。デュースなしでは、それぞれ3-3／6-6の次の1ポイントで決着する。初期値は3ゲームのみデュースなし、5・7・9ゲームはデュースありとする。

有償の最新版ルールブックを入手した際は、ここで定義したルールと `ScoreRuleEngine` のテストを照合して更新する。
